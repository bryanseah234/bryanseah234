# PRD: theprawnorganisation

## Overview
The Prawn Organisation's GitHub profile repository (`theprawnorganisation/theprawnorganisation`). The special-named repo whose README appears on the maintainer's GitHub profile page. Contains a personal bio describing the maintainer as a Singapore-based photographer, videographer, and developer who codes in Python and founded Prawn Productions.

## Goals
- Display a personal biography on the maintainer's GitHub profile page
- Introduce the maintainer's interests: photography (long exposure, landscape), videography, technology, Python coding
- Link to Prawn Productions (Facebook/YouTube)

## Non-Goals
- Interactive features
- Dynamic content
- Portfolio showcase (handled by theprawnorganisation.github.io and theprawnhome)

## Content
- Photographer from Singapore
- Long exposure and landscape photography
- Filmmaker / video content creator  
- Tech enthusiast, learning Python
- Founder of Prawn Productions (Facebook, YouTube)

## Architecture
```
theprawnorganisation/
└── README.md    # Profile bio (rendered on GitHub profile page)
```

## Deployment
Automatically rendered on `github.com/theprawnorganisation` when repo is named `theprawnorganisation`.

## Constraints & Notes
- This is a GitHub "special repository" — the README content appears verbatim on the public GitHub profile
- No code in this repo — documentation-only
- Updates to README immediately reflect on public GitHub profile

Machine-specific values in this document use privacy placeholders.
